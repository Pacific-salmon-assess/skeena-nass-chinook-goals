# skeena-nass-chinook-goals
Repository data wrangling and analyses to inform Chinook salmon assessment and management in the Skeena and Nass River basins.

Feel free to peruse the work-in-progress docs of [spawner-recruit figures](https://pacific-salmon-assess.github.io/skeena-nass-chinook-goals/R/SR_figs.html) and [model diagnostics](https://pacific-salmon-assess.github.io/skeena-nass-chinook-goals/R/SR_diagnostics.html).
